# 实验覆盖与验证限制

[English](paper_coverage.md)

配置覆盖、功能正确性和 GPU 实测性能是不同的结论。本分发包包含代码、运行输入
和命令，不包含历史实验结果。

## 配置与输入

实验目录包含 20 个论文项目、72 个独立设置、301 个设置/方法组合、323 个展开任务，
以及 512-token 扩展和可选 MIN-R 采样数扫描。24 个方法 ID 含别名，
论文矩阵使用其中 13 个。`run_i` 标记运行次数，不是随机种子。

七份正常请求集、14 个模型配置、成本表和输出长度分布支持调度运行。
它们是运行输入，不是端到端实验输出。发布包不包含论文图数组、实测时间表、
日志索引、历史调度计划或结果基线。

## 通过检查的含义

`validate.sh` 检查源码/输入完整性与合成功能，不进行新的调度搜索；
`validate_cpu` 显式运行代表性调度用例，检查完成状态、方法和输入身份、
计划结构、成本一致性、源码路径与 GPU 保护。

这些检查不宣称与旧实验输出一致。需要比较时，可显式提供外部基线或日志。
仅运行 CPU 的日志即使没有 GPU 计时，也可能包含合法的完整调度。
方法名、修改时间和输出相同不能证明源码版本一致。

发布版包含 GPU 执行路径，但 CPU 测试不能证明目标硬件构建、推理、求解器授权、
完整搜索矩阵的正确性或性能。GPU 实验见 [环境指南](../env/README.zh-CN.md#gpu-runtime)，
绘制新收集的结果见 [快速开始](cpu_quickstart.zh-CN.md)。
