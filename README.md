Implementation of Mil, which is built on top of vLLM.

To run Mil, please first install vLLM (using the source code in this repo).

The core of Mil is in the ``benchmarks'' folder.

The code structure is in benchmarks/MY_README.md.

About the process of of building the cost model for a new model, please refer to benchmarks/add_a_new_model.md.

To run the experiments in the paper, please refer to benchmarks/run_end2end_exp.sh.
